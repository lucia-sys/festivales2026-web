# festivales2026-web
página web con varios festivales que van a suceder en España en 2026 (no son reales)

--Descripción del proyecto--

Este proyecto consiste en el desarrollo de una página web estática responsive titulada “Festivales España 2026”, creada utilizando Bootstrap 5 mediante CDN. La finalidad del sitio es presentar información sobre próximos festivales en España en el año 2026 de forma clara, estructurada y adaptable a dispositivos móviles, tablets y ordenadores.

La página incluye una barra de navegación, una sección principal de presentación (hero), una sección con los próximos festivales organizados en tarjetas, una sección informativa sobre el proyecto y un footer con información adicional y enlaces a redes sociales.

Secciones utilizadas y sistema de columnas

La estructura del sitio se ha desarrollado utilizando el sistema de grid de Bootstrap. La sección “Próximos Festivales” emplea una fila (row) con tres columnas col-md-4, lo que permite mostrar tres tarjetas en pantallas medianas y grandes, y una sola columna en dispositivos pequeños. La sección “Sobre Nosotros” utiliza una columna col-12 dentro de una fila, ocupando el ancho completo. El footer se organiza en dos columnas col-12 col-md-6, que se muestran apiladas en móvil y en paralelo en pantallas medianas o superiores.

--Componentes de Bootstrap utilizados--

Se han utilizado componentes prediseñados de Bootstrap como Navbar, Cards, Buttons y el sistema de Grid. También se han aplicado clases de utilidades para espaciado, colores, flexbox e imágenes responsive (img-fluid). Bootstrap se ha incorporado mediante CDN.

--Descripción de los commits--

Durante el desarrollo se realizaron varios commits significativos. En el primero se creó la estructura básica del documento HTML y se añadió el Navbar y la sección principal. En el segundo se implementó la sección de festivales utilizando el sistema de grid y las tarjetas. En el tercero se añadió la sección informativa y el footer. Finalmente, se realizaron ajustes de diseño, espaciado y revisión del comportamiento responsive.
